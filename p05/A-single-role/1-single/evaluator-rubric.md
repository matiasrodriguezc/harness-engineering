## Remaining defects (most important first)

1. **Status bar shows blank values.** `indexing:status` returns `IndexStatus` (`status`, `currentIndexed`, …) but the renderer reads it as `AppStatus` (`indexStatus`, `documentsLoaded`), so it renders "Index: Documents:". Pre-existing and outside this feature, but visible on every screen.
2. **The "+ Import" button does nothing** (`App.tsx` `handleImport` only logs). Without the dev tools or the smoke script, a user cannot add documents, so they cannot get cited answers. Pre-existing.
3. **Document status never becomes "indexed"**: after indexing, DocumentDetail still shows "Status: imported" and an "Index Document" button (`03-citation-open.png`). Pre-existing.
4. **A corrupt `qa-history.json` is silently overwritten.** `getHistory()` logs and returns `[]`, and the next `ask()` writes over the file, so the old history is lost. It should back up the bad file first.
5. **Accessibility is not verified with assistive tech**: no screen-reader pass, no Tab-only walkthrough, no contrast measurement. The sidebar tabs lack the tablist pattern and `DocumentList` items are not focusable.
6. **The follow-up heuristic is narrow**: context is used only when the question alone matches *zero* chunks. A follow-up that matches weakly on its own (e.g. "what about its size?") ignores the previous turn. Answers are still the existing mock patterns, not generated from the conversation.
7. **Relative timestamps do not refresh** while the app stays open (no timer re-render).
8. **Scalability**: the whole history renders every time (no virtualization or paging), and each `ask()` reads and rewrites the entire history file.
9. **Not exercised end to end**: the "Document no longer available" disabled state, Dismiss, the example-question buttons, Shift+Enter, the history-load-error alert.
10. **Environment**: the user's shell sets `NODE_OPTIONS=--openssl-legacy-provider`, which Electron refuses to start with. `npm run dev`/`npm run smoke` must be run with `NODE_OPTIONS=` cleared (documented in `docs/ARCHITECTURE.md`).
11. **The preload duplicates the IPC channel map** (needed because sandboxed preloads cannot `require` local modules). `tsc` catches drift, but a bundled preload would remove the copy. `check-architecture.sh` should also learn to check preload.
12. **The smoke test writes to the real system clipboard** of the machine running it.
